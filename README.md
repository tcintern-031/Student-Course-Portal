# Student Course Portal

A responsive multi-page web application built using Next.js App Router.

## Features

- Home Page
- Courses Page
- Instructors Page
- Contact Page
- Dynamic Course Details
- Search Courses
- Related Courses
- Featured Courses
- Shared Layout
- Navbar
- Footer
- Loading UI
- Custom 404 Page
- Reusable Components
- Responsive Design

## Technologies

- Next.js
- React
- Tailwind CSS
- JavaScript
